Chiến lược điểm

Thông số môi trường theo giai đoạn

Ngưỡng được lưu thành hồ sơ, đổi bằng một nút trên dashboard và gửi xuống Arduino. Mặc định là bào ngư · ra quả thể. Giá trị tham khảo, chỉnh được.

Bào ngư · ra quả thể (mặc định)22–28 °C85–95 %200–500 lux, 6:00–16:00Mỗi 3 giờ

DHT22 đo được 0–100% RH, phù hợp dải 85–95% của nhà nấm. Ánh sáng chỉ được đánh giá trong khung giờ chiếu sáng; Pi giữ đồng hồ và báo cho Arduino biết đang trong khung giờ hay không.

Kiến trúc 3 tầng

Arduino tự đánh giá trạng thái và bật đèn, còi tại chỗ, nên vẫn cảnh báo được khi Pi tắt. Pi lo phần cần đồng hồ, lưu trữ, gợi ý hành động và giao diện. Nét đứt là phần để sẵn, bật khi có linh kiện.

Sơ đồ đấu nối phần cứng

Mạch chính chỉ có 2 cảm biến, 4 thiết bị báo hiệu và LCD. Phần nét đứt xám là HC-05 và TM1637, chưa lắp, chân đã chừa sẵn.

Linh kiệnNối vàoGhi chú đấu nối
DHT22D2VCC 5V, điện trở 10kΩ từ DATA lên 5V (bỏ nếu là module 3 chân đã có trở). Đọc tối đa mỗi 2 giây
LDRA05V → LDR → A0 → 10kΩ → GND. Sáng hơn thì giá trị lớn hơn. Đổi ra lux ước lượng, hiệu chuẩn bằng app đo sáng trên điện thoại
LED xanh lá / vàng / đỏD5 / D6 / D7Mỗi LED nối tiếp 220Ω, cực âm về GND. Chỉ một đèn sáng tại một thời điểm, giống đèn giao thông

  • Dòng 2: ánh sáng và kênh đang nối với Pi (USB, BT hoặc -- khi mất kết nối)

Đánh giá trạng thái và quy trình xử lý

Hệ thống không tự điều khiển môi trường. Nó xếp mỗi thông số vào 3 mức, báo bằng đèn, còi, LCD, dashboard, và nói rõ người vận hành nên làm gì.

MứcĐiều kiệnBáo hiệu
OKMọi thông số trong ngưỡng của hồ sơLED xanh lá
CHÚ ÝCó thông số lệch khỏi ngưỡng nhưng chưa quá biên (2 °C, 5% RH, 30% lux), hoặc lệch quá biên chưa tới 60 giâyLED vàng, LCD dòng 3–4, dashboard
NGUY HIỂMLệch quá biên liên tục trên 60 giây, hoặc DHT22 lỗiLED đỏ, buzzer, LCD, dashboard, ghi bảng alerts

Ngưỡng có vùng trễ: trạng thái chỉ quay về OK khi thông số đã vào trong ngưỡng thêm 0.5 °C hoặc 2% RH, để đèn không nhấp nháy quanh mép ngưỡng. DHT22 bị coi là lỗi khi đọc thất bại 3 lần liên tiếp hoặc giá trị nhảy bất thường (hơn 5 °C hay 20% RH trong 2 giây).

Từ các mốc thời gian này, dashboard tính thời gian phản hồi (từ lúc cảnh báo đến lúc nhận) và thời gian khắc phục (đến lúc thông số về ngưỡng). Đây là phần mở rộng ngoài yêu cầu, phù hợp mục điểm thưởng sáng tạo.

Giao thức truyền thông

Hiện tại dữ liệu đi qua USB Serial 115200 baud. Firmware gửi cùng khung lên cả cổng USB và cổng HC-05 ngay từ đầu, nên khi gắn HC-05 thì không phải sửa code Arduino; Pi đọc cả hai kênh, bỏ khung trùng theo seq.

Arduino → Pi · mỗi 2 giây · một dòng JSON kết thúc bằng \n
{"seq":1532,"t":26.4,"h":81.2,"lux":312,"light":0,"st":1,"f":4,"d":0,"bz":0,"mu":0,"lp":1,"err":0}
st: 0 OK · 1 CHÚ Ý · 2 NGUY HIỂM
f : bit thông số đang lệch (T thấp, T cao, RH thấp, RH cao, sáng thấp, sáng cao, lỗi cảm biến)
d : bit thông số đã ở mức NGUY HIỂM   bz: còi đang kêu   lp: đang trong giờ chiếu sáng

Pi → Arduino · lệnh dạng văn bản: #id|LỆNH|tham số
#21|TH|22,28,85,95,200,500   ngưỡng tMin,tMax,hMin,hMax,luxMin,luxMax
#22|LP|1                     đang trong khung giờ chiếu sáng

Sơ đồ bên phải mô tả cơ chế chuyển kênh, chỉ chạy khi đã gắn HC-05. Nếu mất kết nối với Pi, Arduino vẫn đánh giá theo ngưỡng cuối cùng nhận được (lưu trong EEPROM) và vẫn bật đèn, còi tại chỗ.

Lưu trữ dữ liệu

SQLite, một file mycoguard.db. Ghi số đo mỗi 5 giây, khoảng 17.000 dòng mỗi ngày.

CREATE TABLE readings (
  id INTEGER PRIMARY KEY, ts TEXT NOT NULL, seq INTEGER,
  temp REAL, humidity REAL, lux INTEGER,
  status INTEGER,                    -- 0 OK, 1 CHÚ Ý, 2 NGUY HIỂM
  link TEXT                          -- 'USB' | 'BT' | 'SIM'
);
CREATE TABLE alerts (
  id INTEGER PRIMARY KEY, opened_at TEXT, level INTEGER, metric TEXT,
  value REAL, message TEXT, suggestion TEXT,
  acked_at TEXT, handled_at TEXT, resolved_at TEXT,
  state TEXT                         -- OPEN | ACKED | HANDLED | RESOLVED | REOPEN
);
CREATE TABLE human_actions (
  id INTEGER PRIMARY KEY, ts TEXT, alert_id INTEGER REFERENCES alerts(id),
  action TEXT,                       -- 'Phun sương', 'Mở cửa thông gió', ...
  operator TEXT, note TEXT
);
CREATE TABLE commands (
  id INTEGER PRIMARY KEY, ts TEXT, cmd TEXT, args TEXT,
  status TEXT, retries INTEGER, latency_ms INTEGER, link TEXT
);
CREATE TABLE profiles (
  id INTEGER PRIMARY KEY, name TEXT, t_min REAL, t_max REAL, h_min REAL, h_max REAL,
  lux_min INTEGER, lux_max INTEGER, light_on TEXT, light_off TEXT,
  vent_remind_hours INTEGER, active INTEGER DEFAULT 0
);
CREATE INDEX idx_readings_ts ON readings(ts);

Mô phỏng phía Pi

  • Arduino ảo nói đúng giao thức thật, thay cho cổng USB
  • Mô hình nhà nấm: nhiệt và ánh sáng theo ngày đêm, độ ẩm giảm dần khi không tưới
  • Bảng “hành động người vận hành” (chỉ có trong mô phỏng): phun sương, mở cửa, bật đèn, che sáng. Bấm vào thì môi trường mô phỏng thay đổi, để thử trọn quy trình cảnh báo → xử lý → khắc phục
  • Kịch bản: trưa nắng nóng, khô hanh, DHT22 hỏng, mất kết nối (và mất Bluetooth để thử chuyển kênh trước khi mua HC-05)
  • Chạy: python run.py --link sim

Mô phỏng phía Arduino

  • Dự án Wokwi (diagram.json) với Uno, DHT22, cảm biến ánh sáng, LCD2004 I2C, 3 LED, buzzer
  • Kéo thanh trượt nhiệt độ, độ ẩm, ánh sáng trên Wokwi để thấy đèn đổi màu, còi kêu, LCD đổi gợi ý
  • Gõ lệnh #1|MUTE|1 trong Serial Monitor để thử chiều ngược lại

Công nghệ: Arduino C++ (thư viện DHT, LiquidCrystal_I2C, SoftwareSerial, EEPROM; không dùng String để tiết kiệm RAM 2KB), Python 3 trên Pi (Flask, pyserial, sqlite3 có sẵn), biểu đồ canvas tự viết.

Kịch bản video demo

  • Giới thiệu mạch, LCD và đèn xanh ở trạng thái OK
  • Đặt hồ sơ “ra quả thể” (cần 85–95% RH) trong phòng khô → đèn vàng, rồi đỏ, còi kêu, LCD gợi ý phun sương
  • Trên điện thoại: bấm Đã nhận (còi tắt), làm ẩm cảm biến bằng khăn ướt hoặc hà hơi, bấm Đã xử lý → độ ẩm về ngưỡng, cảnh báo chuyển Đã khắc phục, hiện thời gian phản hồi
  • Che LDR trong khung giờ sáng → cảnh báo thiếu sáng; gửi lời nhắn từ web lên LCD
  • Rút cáp USB vài giây → dashboard báo mất kết nối, Arduino vẫn tự báo đèn tại chỗ; cắm lại → dữ liệu chạy tiếp
  • Mở biểu đồ, bảng lịch sử, nhật ký xử lý, xuất CSV, mở file SQLite
